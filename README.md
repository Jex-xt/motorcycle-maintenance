# 🏍️ Motorcycle Maintenance – NoSQL 🛵

## Haaga-Helia University of Applied Sciences – NoSQL Course Project

**Author:** Pertti Paananen

## Description
A simple Python console application for managing motorcycle maintenance records using MongoDB.

## Features

- Add, view, edit, and delete motorcycles.
- Add, view, edit, and delete maintenance records.
- Store multiple service tasks in a single maintenance record.
- Display maintenance history sorted by date.

## Requirements
- Python 3
- MongoDB
- PyMongo

## Run the application:

```
python motorcycle_maintenance.py
```
